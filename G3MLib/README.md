# G3MLib

G3MLib is a .NET library for reading and editing GameMaker DATA, compiling and decompiling GML, exporting resources, creating and applying patches, merging changes, and generating difference reports.

The package version is **1.0.1** and its target framework is **.NET 10**. It has no application window or game launcher. An application using the library supplies its own interface, paths, progress display, and script interaction.
