# Interface

The main window has **Mods Browser**, **Library**, and **Settings** views. Settings can hide the browser or Library tab, and plugins can contribute their own enabled views.

| Area | Purpose |
| --- | --- |
| [Title bar](title-bar.md) | Auxiliary windows, help, and window controls |
| [Mods Browser](mods-browser.md) | GameBanana search and downloads |
| [Mod details](mod-details.md) | Description, screenshots, files, and links |
| [Library](library.md) | Installed mods, profiles, selection, and diagnostics |
| [Settings](settings.md) | Game paths, appearance, application behavior, and Catalog |
| [Status bar](status-bar.md) | Launch action, selected mode, progress, and messages |

Hover an icon to read its tooltip. Use **Tab** to move keyboard focus and **Enter** or **Space** to activate a focused control. [Scaling](scaling.md) changes interface size; [appearance](../customization/README.md) controls colors, font, and media.
