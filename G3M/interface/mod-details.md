# Mod details

**Details** on a Mods Browser card opens a panel with the upload's information.

The left column has **Open Homepage** (when the mod lists a homepage), the title, the description, a screenshot carousel, and these rows when the data exists: **Mod Version:**, **Authors:**, **Updated:**, **Created:**, **Downloads:**, **Category:**, **Tags:**. For a mod on the G3M Verified list it also shows **G3M compatibility:**, **Game Version:**, and **Note:**. Dates follow the system region format. The right column holds the **Full description:**.

Screenshots have previous and next buttons and position dots. Right-click a screenshot for **Open image in browser**, **Copy image**, and **Copy image URL**.

The buttons at the bottom are **Download** (**Delete** for a mod already in the Library, matching its card) and **Close**. **Escape** also closes the panel.

Multiple upload files can represent different game releases, platforms, optional components, or previous mod versions. Choose by the author's description rather than file order.

Screenshots and descriptions come from the online entry. They say nothing about the package you download. Review any import confirmation and check the mod's game requirement before selecting **Use**.
