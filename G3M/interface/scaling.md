# Interface scaling

Set **Settings > General > UI Scale** from 50% to 200% in 10% increments. The setting changes G3M's interface size, including controls, icons, and dialogs.

Operating-system display scaling also affects the window. Start with the system's normal scaling, then adjust G3M if its controls are too large or small for your display.

**Fullscreen** controls the main window's presentation. It is independent of the launched game's display mode. A custom font can alter text width; check long labels and dialogs after applying one.

Reset the scale through the setting's reset control when reset buttons are enabled. Theme packages do not store UI Scale.
