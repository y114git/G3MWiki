# Supported games

| Game | Configuration ID | GameBanana browsing | Full Install |
| --- | --- | --- | --- |
| DELTARUNE | `deltarune` | Yes | No |
| DELTARUNEdemo | `deltarunedemo` | No | Yes |
| UNDERTALE | `undertale` | Yes | No |
| UNDERTALE Yellow | `undertaleyellow` | Yes | Yes |
| Pizza Tower | `pizzatower` | Yes | No |
| Sugary Spire | `sugaryspire` | Yes | Yes |
| FRICKBEARS3 | `frickbears3` | No | Yes |

**Full Install** downloads a game package where that feature is available. It is disabled on macOS. See [Full Install](full-install.md) for its requirements.

DELTARUNE exposes Main Menu and Chapter 1 through Chapter 5 sections. A section appears in G3M's interface independently of whether its files exist in your installation. Select only sections available in the installed game.

Other built-in games use one mod section. [Custom games](custom-games.md) also use one section and can provide optional Steam and GameBanana IDs.

Use [Game Manager](game-manager.md) to show, hide, and reorder entries. Configure installation paths separately in **Settings > Game**.
