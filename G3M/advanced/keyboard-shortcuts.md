# Keyboard controls

| Input | Action |
| --- | --- |
| `Ctrl` + `+` or `Ctrl` + `=` | Increase G3M interface scale |
| `Ctrl` + `-` | Decrease interface scale |
| `Ctrl` + mouse wheel | Adjust interface scale |
| `Tab`, `Shift` + `Tab` | Move focus between controls |
| `Space` on a focused mod card | Click the card |
| `Enter` on a focused mod card | Open its details |
| `Escape` in mod details | Close the details overlay |
| Double-click a chapter tab, except Menu | Ask whether to turn direct launch on or off for that chapter |
| Double-click empty title-bar space | Maximize or restore the main window |

The interface scale ranges from 50% to 200%, in steps of 10%. Menu cannot use direct launch, because it is already the default starting point.

During onboarding, Enter, Right, and Left move through the tour; Escape dismisses it. **Help > Getting Started** reopens it.

Desktop launch files are a separate feature: see [Shortcuts](../features/shortcuts.md).
