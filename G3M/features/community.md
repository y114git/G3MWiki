# Community

Community displays GameBanana submissions. The **Game** selector limits results to a configured game; **All games** combines available feeds. The **Feed:** list has **New** and **Featured**. Dates follow the system region format. **Close** shuts the window.

Built-in and custom games need a GameBanana ID for their feeds. Plugins can supply additional HTTPS RSS feeds while enabled.

Items can be mods, tools, sounds, skins, or other submissions. Open an item to visit its source page. Viewing a feed item does not import it into the Library.

Each item has an **Open** button. Use **Refresh** to request the selected feeds again. With All games selected, results from successful feeds can still appear if another feed fails. If no feed loads, check connectivity and the reported error.
