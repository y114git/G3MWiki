# Mods

A Library mod is a folder containing `mod_config.json` and its payload files. The configuration identifies the game and lists operations that patch, copy, or extract files when you apply the mod.

[Import](importing.md) a downloaded package, or [create](creating-mods.md) one with the desktop or web editor. Select **Use** on its Library card to include it in the current launch selection.

| Task | Guide |
| --- | --- |
| Install an archive, folder, patch, or URL | [Importing](importing.md) |
| Describe operations and dependencies | [Configuration reference](mod-config.md) |
| Change metadata or files | [Mod Editor](mod-editor.md) |
| Work in a browser | [Web editor](web-editor.md) |
| Keep checkpoints | [Mod Versions](mod-versions.md) |
| Share a package | [Exporting](exporting.md) |
| Combine mods | [Priority and steps](modpacks.md) |
| Import Pizza Tower community formats | [PizzaOven and CYOP/AFOM](po-conversion.md) |

The normal launch mode applies selected mods for a session and restores affected files after exit. [Other launch modes](../games/launch-modes.md) deliberately keep the applied changes.
