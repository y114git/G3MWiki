# Changelog

Release notes for every version are on the GitHub releases page of G3MStudio: `https://github.com/y114git/G3MStudio/releases`. This page points there and says how to read the version.

## Find your version

**Help > About G3MStudio** shows the version. **Help > Copy Diagnostics** copies the version information for a report. The version in this documentation is 1.0.0.

## Update

**Help > Check for Updates...** offers a newer release (see [Updating](../getting-started/updating.md)). A pre-release build is offered newer pre-releases too.
