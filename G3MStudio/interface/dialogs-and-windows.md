# Dialogs and windows

This page lists the windows that belong to the interface area: the title as shown, how to open each one, and what it is for. Windows of other areas link to their own pages.

| Title | Open with | Purpose |
|---|---|---|
| Go To | `Ctrl+T`, `Ctrl+P` | Search over everything. See [Command palette and Go To](command-palette-and-go-to.md). |
| Commands | `Ctrl+Shift+P` | The same box with the `>` prefix. |
| Saved layouts | Layout > Saved Layouts... | Load, rename, delete saved layouts. See [Docking and layouts](docking-and-layouts.md). |
| Save current layout | Layout > Save Layout... | Name and save the arrangement. |
| Notifications list | Status bar button | List of messages. See [Notifications](notifications.md). |
| Sort and filter | Explorer title row button, or the "{count} hidden" footer | Sort, types, code entry rules. See [Explorer filter and sorting](explorer-filter.md). |
| New {type} / Duplicate {name} / Delete {name} | Explorer context menu, File > New, Edit | See [Explorer context menus](explorer-context-menus.md). |
| New folder, New collection, Add tag, Move to folder, Add to collection, Colour | Organize menu, Edit > Add Tag... | See [Folders, collections and tags](explorer-organizing.md). |
| Rename {count} entries | Organize > Rename with Pattern... | Bulk rename. |
| Move to texture group, Move to audio group | Organize menu | Choose a group. |
| Dead Resources | Organize > Find Dead Resources... | Resources nothing uses. |
| Unsaved changes | Closing a file with edits | Save, or keep edits for later. |
| Data file not found | Opening a recent file that is gone | Locate or remove it. |
| Save | Save with the ask-before-saving prompt | Choose save mode. |
| About G3MStudio | Help > About G3MStudio | Version info and **Copy Version Info**. |
| Transfer Resources | File > Transfer Resources... | Import, export, copy, mods. See [Projects](../projects/README.md). |
| Copy to Other Data File | Edit > Copy to Other Data File... | Copy resources between files. |
| Strings | Tools > Strings... | Edit game strings. |
| Room Order | Tools > Room Order... | Order of rooms. |
| Creation order | Room > Instance Creation Order... | Instance order of a room. |
| Convert image to tile layer | Room > Convert Image to Tile Layer... | See [Rooms](../world/README.md). |
| Import sheet or strip | Sprite > Import Sheet or Strip... | See [Sprites](../graphics/README.md). |
| Repack texture pages | Tools > Repack Texture Pages... | Rebuild texture pages. |
| Generate sound, Record sound | Sound menu | See [Audio](../audio/README.md). |
| Plugins | Tools > Plugins... | Manage plugins. |
| Hex View of Data File | Tools > Hex View of Data File... | See [Code tools](../code/README.md). |
| Settings | File > Settings, `Ctrl+,` | Opens as a page over the work area, not a window. See [Settings](../settings/README.md). |
| Getting Started, Interface Tour | Help menu | Onboarding. See [Getting started](../getting-started/README.md). |
| Send Feedback, Report a Problem | Help menu | Send a report. |

Floating panels also open as windows of their own (see [Docking and layouts](docking-and-layouts.md)).
